# Lessons

Corrections from real design work that are general enough to change the skill. Each entry is added only after the owner agrees, and contains no project-identifying detail. When this file reaches about 20 entries, or two lessons contradict a principle, they are consolidated into `references/principles.md` (procedure in `references/evolve.md`).

Format:

```markdown
## <short title>
- Symptom: <what the reader saw or felt, in generic terms>
- Rule: <the one-line rule that prevents it>
- Check: <how to see it on a render or artifact>
- Date: <YYYY-MM-DD>
```

No open lessons. Lessons already consolidated are listed in CHANGELOG.md.
