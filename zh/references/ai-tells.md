# AI 味特征

动手做任何新建界面之前读，每次 T1 和 T2 关卡时也读。

没有锚点时，模型会退回一套默认套件，读者一眼就能认出是生成的。下面每一项，只要在锚点没有要求时出现，就算一条发现。没有哪一项绝对禁止：项目的设计系统或品牌手册定义了它，就按定义使用。`scripts/lint-design.mjs` 能检测标有（lint）的几项。

## 界面

| 看到 | 改为 | 检查 |
|---|---|---|
| 锚点没有要求、默认选用的米色、浅褐色或带色调的页面背景（lint） | 白色，或锚点规定的页面颜色；只有以图为主的页面，在适合作品并写进规格时，才用纸张感的米白或深色底（`graphic.md`） | 取样页面背景：与规格里的页面颜色一致 |
| 左侧带粗彩色竖条的提示框（lint） | 一句平实的话，放在细线框或提示条里，状态图标加正文色文字，并附上操作 | 没有 3px 及以上带颜色的 `border-left` |
| 标题上方全大写、加字距的眉标（lint） | 用第二级文字颜色、按常规大小写书写的标签（适用于拉丁文字；中日韩文字的标签不加字距和装饰即可）；标题已经说了同样的话，就删掉 | 没有同时带 `letter-spacing` 的 `text-transform: uppercase` |
| 每个状态一个彩色胶囊（lint） | 带图标的彩色状态文字；只在锚点定义了胶囊的地方用胶囊 | 数渲染图上的胶囊：锚点没有就为零 |
| 每个分组都套一张带圆角和边框的卡片 | 分组之间用间距，层级之间用细线；只有整项可点的内容才用卡片 | 数带边框或阴影的框：只有整项可点的目标和浮层表面 |
| 页面流里的卡片带阴影（lint） | 页面流里不用阴影；菜单、弹出框、对话框用一种分层阴影 | 每个 `box-shadow` 都属于浮层表面 |
| 用虚线边框表示「待定」或空（lint） | 按原则 10 用位置和容器区分，再加一个平实的标签 | 没有虚线边框 |
| 用环形图表示单个比例 | 直接写数字和分母（「12 项中的 7 项」） | 没有只显示一个值的圆形图表 |
| 一排 3–4 张大数字 KPI 卡片 | 一条数字带：数字排成一行，同一字号，标签在下方，不加框 | 每屏最多一个展示字号的数字 |
| 一屏上出现三种状态色（琥珀、绿、红） | 一个强调色，加上当前要紧的那一种状态 | 数渲染图上的色相：强调色加最多一种状态色 |
| 默认用衬线标题配无衬线正文 | 默认只用一个字体家族；两个家族各有明确分工并写进规格时，才声明一对（例如衬线用于标题，无衬线用于数据） | 数字体家族：一个，或已声明的那一对 |
| 浅色页面里一块深色的主视觉卡片 | 主角用页面本身的颜色，靠尺寸和位置占据主导 | 锚点没有规定时，不出现反色背景的区块 |
| 每个图标后面垫一个浅色圆底 | 图标单独使用，用文字颜色；或者不用图标 | 图标周围没有实心圆 |
| 渐变、光晕、玻璃（lint） | 只在锚点规定了品牌唯一的识别性图形手法（例如渐变或图案）时使用，而且只用在一处（封面、首屏） | 渐变和模糊最多出现一次，并且锚点里有 |
| 用 emoji 当图标，或混用几套图标 | 一套线宽一致的图标，或者不用 | 所有图标的线宽和转角样式相同 |
| 全部居中 | 左对齐到同一条边距；只有封面上单独一行短文字才居中 | 在 25% 渲染图上文字边缘对齐 |
| 凑数的插图或图库素材 | 真实素材，或只用字体排印和留白 | 每张图都是真实素材或作品本身 |
| 写着「Success!」的状态或成功提示 | 用几个词写出结果（「已保存」「链接已复制」）；变化本身看得见时不提示 | 提示里没有「成功」，没有感叹号 |

## 幻灯片和文档

| 看到 | 改为 | 检查 |
|---|---|---|
| 每页幻灯片都有色调底或渐变 | 正文页用素净的底色；品牌的识别性图形手法（如果有）只放在封面和封底 | 正文页都用同一种素净的页面颜色 |
| 幻灯片上带圆角和阴影的内容卡片 | 圆角 0，不用阴影；靠网格和水平线分组 | 所有页面都没有阴影 |
| 展示字体加口号式标题 | 默认只用一个字体家族，或按上文声明一对；每个标题或导语都是一句完整的结论 | 按顺序读导语，能读出完整的内容 |
| 每页都有一块渐变标志 | 标志放在封面和封底；正文页最多一个小的页眉标记 | 正文页上的标志最多是一个小的页眉标记 |
| 带图例的环形图 | 柱形图，数字写在柱上，直接标注，只留基线 | 没有图例，没有网格线 |
| 用图标和人形小图装饰要点 | 不用图标，要点由文字表达 | 数图标：不承载含义就为零 |

## 这份清单怎么用

1. 动手之前：写出锚点要求的几项，其余一律不用。
2. 关卡上：运行 `scripts/lint-design.mjs`，再对照两张表检查渲染图。
3. 每条命中：去掉，或者指出要求它的锚点条目。新发现的、反复出现的特征，按 `evolve.md` 写进 `LESSONS.md`。
