# 动效

做任何会动的内容时读，所有者说产品僵硬、没生气或卡顿时也读。只用锚点（或 `assets/tokens.css`）里的动效令牌。

## 1. 该不该动？

只有动效承担下面三项作用之一时才使用：
- 说明元素从哪里来、到哪里去（底部弹层从下方升起，删掉一行后空位合拢）；
- 确认一次输入（按下、切换、打勾）；
- 显示两个状态之间的连续性（一行展开成它的细节，指示器滑到新的标签）。

操作越频繁，动效越少。读者一天做几百次的操作，只给状态变化，不加其他效果。动效不能延迟输入。

## 2. 按角色选缓动

| 角色 | 缓动 | 令牌 | 默认值 |
|---|---|---|---|
| 进入（出现、打开） | ease-out | `--ease-out` | `cubic-bezier(.2, .8, .2, 1)` |
| 离开（消失、关闭） | ease-in，比进入更短 | `--ease-in` | `cubic-bezier(.4, 0, 1, 1)` |
| 在屏幕上移动或改变尺寸 | ease-in-out | `--ease-in-out` | `cubic-bezier(.45, 0, .25, 1)` |
| 按下和悬停的反馈 | ease-out，几乎即时 | `--ease-out` | `cubic-bezier(.2, .8, .2, 1)` |
| 小型确认（打勾、开关滑块、徽标） | 轻微回弹 | `--ease-spring-small` | `cubic-bezier(.3, 1.4, .5, 1)` |
| 持续运行的指示（加载圈、进度条） | linear | | |

回弹和弹簧只用于约 64px 以内的小元素，也不用于一整天反复做的操作。不用于对话框、侧边抽屉或底部弹层。不要沿用浏览器默认的 `ease`，要指定角色缓动。

## 3. 按尺寸和距离定时长

| 什么在动 | 手机 | 桌面 |
|---|---|---|
| 悬停和按下 | 约 100–150ms（`--dur-1`、`--dur-2`） | 相同 |
| 小（工具提示、菜单、轻提示、勾选） | 进入约 150–250ms（`--dur-3`），离开 120–200ms（`--dur-2`） | 稍短 |
| 中（对话框、带内容的弹出框、侧边抽屉） | 约 250–350ms（`--dur-3m`） | 约 200–250ms（`--dur-3`） |
| 大（底部弹层、页面转场、全屏展开） | 约 350–500ms（`--dur-4`） | 约三分之二（`--dur-3m`） |

离开比进入短。弹簧的时长是所在档时长 × 约 1.5，就地计算（例如 `calc(var(--dur-2) * 1.5)`）；没有单独的弹簧令牌。用时长令牌（`--dur-1` 到 `--dur-4`，以及 `--dur-3m`）；所有动画用同一个时长是一种毛病。

## 4. 编排

- 一个主元素先动；其他元素错开约 20–50ms 跟上。整个序列的总时长控制在「大」档时长左右。
- 离开时沿进入的路径反向运动。
- 共享元素从点按的位置展开：弹出框从离触发点最近的位置展开，方向与它实际打开的一侧一致；右键菜单从指针处展开；卡片展开成细节，再缩回同一张卡片。
- 进入时移动距离要短（约 8–24px），淡入稍早于位移开始。

## 5. 可打断

- 状态变化立即生效，动画随后播放。
- 任何动画都可以在进行中从当前位置反向；新的输入会接管动画。
- 动画进行时不阻塞输入。
- 手指或指针拖动时 1:1 跟随；松开后按松手时的速度停到较近的一端。

## 6. 属性

- 只对 transform 和 opacity 做动画，filter 慎用。会引起重排的元素，不对 width、height、top、left 或 margin 做动画。
- 不用 `transition: all`；写明属性。
- 动画帧里不交替读取和写入布局。

## 7. 减弱动态效果

- 在 `prefers-reduced-motion: reduce` 下：保留 150ms 以内的透明度和颜色变化；去掉位移、缩放、视差、弹簧和错开。
- 状态变化仍然发生，只去掉运动。

## 8. 检查

- 读计算后的值：每个 `transition` 和 `animation` 都写明属性，用角色令牌和分档时长。
- 帧连拍：用 `scripts/shot.mjs --steps` 加一个 `burst` 步骤，截下过渡的开始、中间和结束；检查开始帧从触发点展开，中间帧没有布局跳动，结束帧与静态状态一致。
- 用 `--emulate-reduced-motion` 运行同样的步骤：没有位移，仍能到达结束状态。
- 按下反馈：输入后约 100ms 内出现按下状态。

动效毛病：
- 页面加载时所有内容都淡入或滑入；
- 大面积表面上的弹跳或回弹；
- 所有动画都用同一个时长；
- 移动的元素用 linear 缓动；
- 卡片和行在悬停时放大；
- 内容滚动进入视野时才动画出现；
- 菜单或弹出框从自身中心展开，而不是从触发点展开；
- 离开和进入一样慢，甚至更慢。
