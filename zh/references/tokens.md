# 默认令牌

项目没有自己的锚点时读：没有设计系统、Figma 文件或品牌手册，所有者也没有指定公开的设计系统。数值在 `assets/tokens.css` 里，可以直接粘贴。

这是一套中性的默认值，沿用 Geist 设计系统和 Web Interface Guidelines 的思路（白色页面、近黑的文字、一个强调色、封闭的尺度）；数值由本 skill 自定，没有照搬两者中的任何一个。把它当作起步用的锚点。项目有锚点时，用锚点的数值，删掉这些。无论用哪一套，都把数值抄进 `DESIGN-NOTES.md`，不用清单以外的值。

## 颜色

| 令牌（token） | 角色 | 用于 | 不用于 |
|---|---|---|---|
| `--page` | 页面背景 | 页面、底部弹层、对话框 | 带色调或米色的背景 |
| `--fill` | 浅填充 | 整项可点的目标、输入框底、表头 | 给每个分组套一张卡片 |
| `--fill-hover` | 悬停和按下的填充 | 行和安静按钮的悬停与按下 | 静态装饰 |
| `--hairline` | 1px 分隔线 | 字号和颜色相同的行与层级之间 | 包住区块的框 |
| `--border` | 强边框 | 输入框、次要按钮 | 卡片 |
| `--text-3` | 第三级文字 | 说明文字、占位符、禁用状态 | 正文 |
| `--text-2` | 第二级文字 | 标签、元信息、按常规大小写书写的区块标签（适用于拉丁文字；中日韩文字的标签不加字距和装饰即可） | 主角 |
| `--ink` | 主要文字、图标 | 正文、标题；没有品牌色时充当强调色 | |
| `--accent` | 唯一的强调色 | 主要按钮、链接、当前导航状态、焦点 | 装饰、区块背景 |
| `--ok` `--warn` `--bad` | 状态 | 带图标的彩色状态文字 | 实心胶囊、区块背景 |

- 每个产品一个强调色。用品牌色替换它；没有品牌色时，设 `--accent: var(--ink)`。
- 一屏上通常最多出现一种状态色；同时出现三种，说明这一屏报告的内容太多。
- 对比度：`--text-2` 和 `--ink` 在 `--page` 和 `--fill` 上达到 4.5:1；`--text-3` 只用于不重要的文字。
- 深色模式是单独调整的一套，不是反色：强调色更亮，状态色更柔和，浮层阴影带一圈细环。

## 字体

| 令牌 | 字号 / 行高 | 角色 |
|---|---|---|
| `--fs-12` | 12 / 16 | 说明文字、脚注、法律文字 |
| `--fs-14` | 14 / 20 | 次要文字、标签、表格单元格 |
| `--fs-16` | 16 / 24 | 正文、输入框（16px 可以防止 iOS 聚焦时放大） |
| `--fs-20` | 20 / 28 | 区块和卡片标题 |
| `--fs-28` | 28 / 36 | 页面标题 |
| `--fs-40` | 40 / 48 | 展示字号，每屏最多一次（一个主数字或封面标题） |

- 只用 400、500 和 600 三个字重。层级先靠字号和颜色，其次靠字重。
- `--font-sans` 先列一款中性的界面无衬线字体，然后是系统字体，再是系统中文字体栈。拉丁字体自行托管；不加载中文网络字体。
- `--font-mono` 只用于代码、编号和需要对齐的时间列。其他数字都用无衬线字体加等宽数字（设在 `body` 上）。
- 中文段落：行高约 1.6，不用负字距，不用斜体，中西文之间自动加空格。

## 间距、形状、线条

- 间距用 4px 网格：4、8、12、16、24、32、48。每个项目从中选定三个常用值：行内一个（8），组内一个（12 或 16），组与组之间一个（32 或 48）。
- 圆角：控件 6，面板、菜单、对话框和图片 8；印刷品 0。嵌套形状要同心：内圆角 = 外圆角 − 内边距。
- `--r-round` 只用于头像和开关的部件，不用于状态胶囊或按钮。
- 用 `--hairline` 颜色的 1px 线分隔层级。优先用细线或留白，少用框。

## 层次（阴影）

- 页面流里的内容都不加阴影：不用带阴影的卡片。
- `--shadow-float` 是唯一的阴影，用于浮在内容上方的表面：菜单、弹出框、对话框、轻提示。

## 控件

- 高度 32、36、40；触摸目标 44（或在较小的可见控件周围留出 44px 的点击区域）。
- 每个视图一个实心按钮，用 `--accent`；次要按钮用 `--border` 或 `--fill`；行内操作只用文字或图标。

## 动效

| 令牌 | 值 | 角色 |
|---|---|---|
| `--ease-out` | `cubic-bezier(.2,.8,.2,1)` | 进入、按下和悬停的反馈 |
| `--ease-in` | `cubic-bezier(.4,0,1,1)` | 离开 |
| `--ease-in-out` | `cubic-bezier(.45,0,.25,1)` | 在屏幕上移动和改变尺寸 |
| `--ease-spring-small` | `cubic-bezier(.3,1.4,.5,1)` | 约 64px 以内的小型确认 |
| `--dur-1` / `--dur-2` | 100 / 150ms | 悬停和按下 / 小的变化和离开 |
| `--dur-3` / `--dur-4` | 250 / 400ms | 小的进入、菜单、弹出框 / 手机上的底部弹层和大面积表面 |
| `--dur-3m` | 300ms | 手机上的中等表面（对话框、带内容的弹出框、侧边抽屉） |

- `--ease`（= `--ease-out`）和 `--dur-sheet`（= `--dur-4`）仍然可用。只对 transform 和 opacity 做动画。
- 减弱动态效果的代码块保留短的颜色和透明度变化，去掉位移。规则见 `motion.md`。

## 焦点

- `--focus-ring`：一圈 2px 页面色的间隙加一圈 2px 强调色的环，只在 `:focus-visible` 时显示。
