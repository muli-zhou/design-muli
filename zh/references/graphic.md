# 平面排版

做幻灯片、报告、作品集、单页、海报和封面时读。12 条原则同样适用；本文件补充固定页面上有哪些不同。海报部分的检验比其他部分少。

两种页面：
- **文档型页面**（幻灯片、报告、作品集、单页）：按顺序阅读，常打印或投影。用固定的网格、封闭的字号尺度、一种颜色，不加装饰。每页的形式保持一致，读者就能专注于内容。
- **吸引型页面**（海报、封面、标题页）：读者路过时看到。原则 3 在大尺度上同样适用：一个元素靠尺寸、对比和周围的留白占据主导，只用一种品牌色。只有焦点图是真实素材或作品本身时才用；否则文字就是视觉焦点。

## 画布与网格

- 先定画布：幻灯片用 1920×1080，印刷品用 A 系列尺寸或印厂的规格。写进 `DESIGN-NOTES.md`。
- 12 栏网格，外边距固定（例如 1920×1080 下左右 96、上 56、下 36）。每个块都在栏边开始和结束。
- 竖向分区逐页固定：标题带、导语、正文、来源行，页脚线放在固定的 y 坐标。到第 2 页，读者就知道该往哪里看。
- 安全边距：所有内容，包括页脚和页码，都不碰到或越过裁切线或投影安全边缘。印刷品另加出血（通常 3mm），并在裁切线内留 5–10mm 的安全边距。
- 有意留白：让一块区域空着，不用形状、图标或色块去填。

## 字体

1920×1080 下的封闭尺度，最多三个字重：

| 角色 | 字号 / 字重 | 说明 |
|---|---|---|
| 封面标题 | 112 / 600 | 只用于封面和封底 |
| 页面标题 | 48 / 600 | 固定在标题带里 |
| 导语 | 32 / 600 | 一句完整的结论 |
| 正文和注释 | 22–24 / 400 | |
| 表格 | 表头 22 / 正文 20 / 注释 18 | |
| 数字带 | 56 / 600 | 每页最多一条；只放数字，非数字的结果写成普通句子 |
| 来源行 | 16 / 400 | 第二级颜色 |
| 页脚 | 15 / 400 | 页眉、章节进度、第 N 页 / 总页数 |

换算到纸张：乘以「页面宽度（pt）÷ 1920」。A4 横向（842pt）约 ×0.44，A3 横向（1191pt）约 ×0.62。下限：换算之后，印刷品上没有小于 8pt 的文字。换算后会低于下限的行（页脚、来源行、A4 上的表格注释）直接设为 8pt，不按比例缩小。

- 默认只用一个字体家族；两个家族各有明确分工并写进规格时，可以声明一对（例如衬线用于标题，无衬线用于数据）。同一家族内的层级先靠字号，再靠字重，不靠颜色；斜体只适用于拉丁文字，所以中日韩文字的幻灯片只用字号和字重。
- 导语是结论句，不是话题标签：写「尺码指南上线后退货下降了 18%」，不写「退货」。按顺序只读导语，就能了解全部内容。
- 每页一条信息。第二条信息放到下一页。

## 颜色与符号

- 一种品牌色，用于标题、线条和主角。第二个强调色只在有且仅有两种已声明的含义、并且只用在少数几页时才用。
- 在 `DESIGN-NOTES.md` 里写一张符号表：每种颜色和线型在所有地方都只表示一件事（实线 = 实际，虚线 = 预测；强调色 = 今年，灰色 = 去年）。灰度打印后也要能分清：靠明度或线型区分，不只靠色相。
- 品牌唯一的识别性图形手法（例如渐变或图案、满版照片、色块）只出现在封面和封底；正文页保持素净。

## 线条、表格、图表

- 只用 1px 的水平线：标题带下方、页脚上方、表格分组之间。不用竖线，不用框，不用斑马纹。
- 表格里的数字右对齐，用等宽数字；表头用一条线分开，不用底色。
- 图表用直角，数字写在柱上，直接标注，只留基线；不用图例，不用网格线，不用环形图。超出简单柱形图和折线图的，用专门的图表工具。
- 所有页面圆角为 0，不用阴影。不用装饰性图标或人形小图。

## 页眉页脚

- 页眉在右上角（分区或章节名），页脚放一条小的分段章节进度条和「N / 总页数」。
- 每个正文页上，页脚和页眉都在固定坐标；封面和封底不放。

## 以图为主的页面（作品集、案例、产品目录）

- 作品是主要的视觉：用大图，文字作辅助。图注字小、用第二级颜色、只写事实（是什么、在哪里、何时、担任什么角色），不用形容词。
- 图片对齐到栏边，与文字共用左边距。
- 标注：在图上用编号标记，对应旁边的编号列表，不用箭头和标注框。
- 页面默认是白色。以图为主的页面，如果适合作品并写进了规格，可以用纸张感的米白或深色底；但不能是没有锚点时默认选用的色调（`ai-tells.md`）。文字颜色随之从同一套令牌里切换。
- 小的分区标签下加一条细线，再配上页眉，长文档就便于查找。

## 海报和封面

- 写下 3 秒内要传达的内容：路过的人必须知道什么。这条信息就是主角，字号放得很大。
- 决定是否参加或是否感兴趣的事实（是什么、何时、何地、费用；「免费」就是其中之一）都要在预期距离下读得清：字高至少约为「距离 ÷ 120」（2 米 → 约 17mm）。细节可以小，但要集中成一个紧凑的块，不能占掉半页。
- 列表用可读字号的竖排短行或分栏，不用「·」或「/」连成一长串。
- 插图要么大、真实、在观看距离下一看就懂，要么不放。
- 次要信息（招募志愿者、赞助方一行字）的字号不大于决定性事实的辅助细节。
- 每个角色一种颜色：一个强调色用于主角和决定性事实，其余都用中性色。

## 交付前检查

1. 溢出和换行：没有文本框溢出；标题或导语的最后一行不会只剩一个词；导语不超过两行。条件允许时，为幻灯片写脚本检查（测量每个文本框）。
2. 按实际尺寸看：按 100% 打印，或在投影仪或尺寸相近的屏幕上看；海报从预期距离看（对 A3 来说，25% 渲染图大致相当于 2 米外）。
3. 灰度检查：用灰度打印或渲染；每种符号仍然能分清。
4. 只读导语：按顺序读导语，内容前后连贯。
5. 用 `references/ai-tells.md`（幻灯片和文档那张表）检查渲染图。
